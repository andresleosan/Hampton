# Specs activas

Estructura SDD adaptada de los apuntes del curso:

`Constitución → spec.md → plan.md → tasks.md → implementación → validación`

- `spec.md`: qué debe hacer la feature y cómo se acepta.
- `plan.md`: archivos, responsabilidades y estrategia de pruebas.
- `tasks.md`: evidencia breve de la demo local; los pendientes transversales viven solo en `specs/plan.md`.

| 002 | Inicio y catálogo residencial | Implementada con snapshot curado |

Las specs conservan el alcance aprobado. El estado anterior no implica cierre completo de todos sus criterios.
